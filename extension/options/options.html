What counts as what

One site per line. Subdomains are included automatically. Add a path to be more specific, e.g. youtube.com/shorts.

How strict is Hackie?

Hackie times your continuous "slack streak". Spend a couple of minutes on work and the streak resets.

Set any step to 0 to turn it off. Once you blow through your daily slack budget, every warning escalates one level.

Effects

AI judge and Ask Hackie optional

Bring your own API key from any provider. The same provider and key power three things:

  • The page judge. Site lists can't tell a lecture from a cat video. With the toggle below on, Hackie sends ambiguous pages (URL, title, description and a short text excerpt) to the model, which decides whether the page helps with your task and writes a personalized nudge.
  • Ask Hackie. A chat agent in the popup's Ask tab and the debug console. It uses tools to read your tracking data (current activity, today, history, settings, debug log) and can mark a site or start a break when you ask. It works whenever a key is set, even with the judge toggle off.
  • Hackie's AI on every nudge. Speech bubbles written for you, plus opening your work tabs or closing slacking ones when you need it. Its switches are at the bottom of this section.

Hackie's AI on every nudge

The AI bubbles, tab actions and the angry AI verdicts need a provider key above; without one, furious refusals and the restore lock still apply. Page snapshots and memory summaries are sent to the chosen provider.

Hackie's memory

Hackie remembers where your slacking time goes, the work pages you actually use, your projects and what the AI learned about you, so it can warn you sooner and send you somewhere useful. It's stored only in this browser. Sensitive sites only ever appear as "Private site".

            Sensitive sites

            Pages on these sites, or web proxies to them, are never described to the AI. The page judge is only told "information blocked: the user is viewing sensitive content", and Ask Hackie only ever sees them as "Private site". Time here counts as slacking and is logged as "Private site", never by name. The default list is the South Korea blocked-sites list; add, remove or edit entries however you like.

            Debug mode

            Adds a small console in the bottom-left corner of every site showing what Hackie sees right now: whether Chrome's window is focused, whether you're idle, whether media is playing, how the page is classified and why, the slack streak, and recent decisions. It also has an Ask Hackie box, so you (or a browser agent such as Claude in Chrome) can ask why Hackie did or didn't react. Websites can't read the console, but it's on screen, so turn it off before screen sharing.

            Your data

            Time stats (the last 60 days) and Hackie's memory stay in this browser. Nothing is uploaded unless you set up an AI provider above.

            Settings file

            Move your settings to another browser, or keep a backup. Only settings, no stats or memory.
